# תעלומת רצח - הוראות העלאה (בלי Firebase)

ארבעה קבצים: `server.js` (השרת), `index.html` (המשחק), `package.json` (הגדרות), `README.md` (הקובץ הזה).
אין צורך בשום הגדרה בתוך הקבצים. פשוט מעלים כמו שהם.

## 1. GitHub (גיטהאב = אתר לאחסון קוד)
1. היכנסו ל-github.com והירשמו (Sign up = הרשמה) אם אין לכם חשבון.
2. לחצו על **+** למעלה ← **New repository** (ניו ריפוזיטורי = מאגר חדש).
3. שם: `murder-game`. לחצו **Create repository** (צור מאגר).
4. לחצו **uploading an existing file** (העלאת קובץ קיים).
5. גררו את ארבעת הקבצים ולחצו **Commit changes** (שמור שינויים).
   הקבצים חייבים להיות בתיקייה הראשית, לא בתוך תיקייה.

## 2. Render (רנדר = שירות שמריץ את האתר שלכם באינטרנט)
1. היכנסו ל-render.com והירשמו עם GitHub.
2. ב-Dashboard (דשבורד = לוח בקרה) לחצו **New +** ← **Web Service** (ווב סרוויס = שירות אינטרנט עם שרת).
3. חברו את ה-repository (ריפוזיטורי = מאגר) `murder-game`.
4. מלאו:
   - **Name** (שם): כל שם.
   - **Runtime / Language** (שפת הרצה): `Node`.
   - **Build Command** (פקודת בנייה): `npm install`
   - **Start Command** (פקודת הפעלה): `node server.js`
   - **Instance Type** (סוג שרת): `Free` (חינם).
5. לחצו **Create Web Service** (צור שירות). אחרי כדקה או שתיים יופיע **Live** (פעיל) ולינק בסגנון `https://murder-game.onrender.com`.

## חשוב לדעת
- בתוכנית החינמית השרת "נרדם" אחרי 15 דקות בלי שימוש, והכניסה הראשונה אחרי זה לוקחת כדקה. פתחו את הלינק כמה דקות לפני המשחק.
- המשחקים נשמרים בזיכרון השרת. אם השרת מתאפס (אחרי עדכון או הרדמות), משחקים פעילים נמחקים. זה בסדר למשחק של 20 דקות.
- עדכון בעתיד: מעלים קובץ חדש ל-GitHub (Add file ← Upload files) ו-Render מתעדכן לבד.

## איך משחקים
אחד לוחץ "פתח משחק חדש" ומקבל קוד בן 4 ספרות. שולחים לחברים את הלינק ואת הקוד. כשיש לפחות 3 שחקנים, המארח לוחץ "התחל", והכניסה ננעלת.
